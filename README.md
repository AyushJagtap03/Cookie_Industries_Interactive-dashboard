# Cookie_Industries_Interactive-dashboard
Created a Sales &amp; Profitability Dashboard for Cookie Industries using Advanced Excel, Power Query, PivotTables, KPI cards, charts, and slicers. Analyzed 700+ transactions, finding ₹19.85 Cr sales, ₹9.67 Cr profit, a 48.7% margin, top products and regions, and 134 loss-making records to support data-driven decisions.
