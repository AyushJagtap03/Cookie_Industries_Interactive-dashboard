# Cookie Industries — Sales & Profitability Dashboard

An interactive Excel analytics project that converts 700+ transaction records into business insights on sales, profitability, product performance, regional performance, and loss-making transactions.

## Project Highlights
- **Gross sales:** ₹19.85 Cr
- **Profit:** ₹9.67 Cr
- **Profit margin:** 48.7%
- **Transaction records analyzed:** 700+
- **Loss-making records identified:** 134
- **Top-performing product:** Vermont (based on project analysis)

## Tools & Techniques
- Microsoft Excel
- Power Query for data cleaning and transformation
- PivotTables and PivotCharts
- KPI cards and interactive slicers
- Formula-based analysis and dashboard visualization
- Sales, profit, margin, product, and regional performance analysis

## Workbook Contents
The workbook contains seven sheets:

1. **Project Overview** — project goals, workflow, and key outcomes
2. **Data** — source transaction data
3. **KPI_Analysis** — headline metrics and supporting calculations
4. **Cleaned_Data** — prepared data used for analysis
5. **Pivot_Units** — product/volume summary
6. **Pivot_Sales** — sales and profitability summaries
7. **Dashboard** — interactive visual dashboard for exploring business performance

## Business Questions Explored
- What are the overall sales, profit, and profit margin?
- Which products and regions contribute most to performance?
- Where are sales and profitability strongest?
- Which transactions are loss-making and may require further review?

## How to Use
1. Download `Cookie_Industries_Sales_and_Profitability_Dashboard.xlsx`.
2. Open it in Microsoft Excel for the best experience with formulas, PivotTables, charts, and slicers.
3. Use available dashboard slicers to interactively explore results.
4. Review the supporting analysis and cleaned-data sheets for additional context.
